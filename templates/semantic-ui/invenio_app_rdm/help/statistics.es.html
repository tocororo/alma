Estadísticas

¿Qué datos se rastrean?

Rastreamos dos tipos de eventos:

  1. Visitas a una página de registro.
  2. Descargas de un archivo.

Para ambos tipos de eventos, recopilamos:

  1. Visitante: Un ID de visitante anonimizado.
  2. Tipo de visitante: Si la solicitud fue hecha por a) humano, b) máquina o c) robot.
  3. País: El país de origen de la solicitud (basado en la dirección IP).
  4. Referente: El dominio de referencia.

¿Qué se considera una vista ?

Un usuario (humano o máquina) que visita un registro, excluyendo dobles clics y robots.

¿Qué es una vista única ?

Una vista única se define como una o más visitas de un usuario dentro de un período de 1 hora. Esto significa que si el mismo registro fue accedido múltiples veces por el mismo usuario dentro del mismo período, lo consideramos como una única vista.

¿Qué se considera una descarga ?

Un usuario (humano o máquina) que descarga un archivo de un registro, excluyendo dobles clics y robots. Si un registro tiene múltiples archivos y descargas todos, cada archivo cuenta como una descarga.

¿Qué es una descarga única ?

Una descarga única se define como una o más descargas de archivos de un mismo registro por un usuario dentro de un período de 1 hora. Esto significa que si uno o más archivos del mismo registro fueron descargados múltiples veces por el mismo usuario dentro del mismo período, lo consideramos como una única descarga.

¿Qué es el volumen de datos descargados ?

El volumen total de datos que ha sido descargado para todos los archivos de un registro por un usuario (humano o máquina), excluyendo dobles clics y robots. En caso de que un usuario cancele una descarga a mitad, igualmente contamos el tamaño total del archivo como completamente descargado.

¿Cómo se manejan las versiones?

Por defecto, para un registro, mostramos los conteos agregados de vistas, descargas y volumen de datos para todas las versiones de un registro. Puedes expandir el cuadro de estadísticas en la página del registro para ver los conteos específicos de cada versión.

¿Cómo se manejan los robots?

Las solicitudes hechas por robots (también llamados crawlers, arañas o bots) son filtradas de las estadísticas de uso. Detectamos robots basados en una lista estandarizada proporcionada por los proyectos COUNTER y Making Data Count.

¿Con qué frecuencia se actualizan las estadísticas de uso?

Una vez al día.

¿Cómo puedo ver los registros más vistos?

Cualquier búsqueda en {{ config.THEME_SITENAME }} te permite ordenar los resultados por " más vistos ".

¿Cómo realizan el rastreo?

Cumplimos con el Código de Prácticas COUNTER así como con el Código de Prácticas para Métricas de Uso de Datos de Investigación en nuestro rastreo. Esto significa que nuestras estadísticas de uso pueden compararse con otros repositorios compatibles con COUNTER.

¿Cuál es la diferencia entre una máquina y un robot?

Una solicitud de máquina es una solicitud automatizada iniciada por un usuario humano, por ejemplo un script descargando datos de {{ config.THEME_SITENAME }} para ejecutar un análisis. Una solicitud de robot es una solicitud automatizada hecha por ejemplo por un rastreador de motor de búsqueda.

¿Cómo anonimizan a los usuarios?

Para cada evento de vista/descarga, rastreamos un ID de visitante anonimizado. Este ID cambia cada 24 horas para un mismo usuario, por lo que un usuario viendo el mismo registro en dos días diferentes tendrá dos IDs diferentes. La razón por la que rastreamos este ID anonimizado es para poder contar vistas y descargas únicas.

Para propósitos de seguridad, también mantenemos un registro de acceso del servidor web que incluye tu dirección IP y la cadena de agente de usuario de tu navegador. Este registro se elimina automáticamente después de máximo 1 año y está estrictamente separado de la recolección de estadísticas de uso.

El ID de visitante anonimizado se genera a partir de un identificador personal como:

  1. un ID de usuario (si estás conectado en zenodo.org),
  2. un ID de sesión,
  3. o una dirección IP y la cadena de agente de usuario de tu navegador.

Combinamos el identificador personal con un valor aleatorio (una sal) y aplicamos una función hash criptográfica unidireccional para codificar los datos. La sal (valor aleatorio) se descarta y se regenera cada 24 horas. Al usar y luego descartar esta sal aleatoria, nos aseguramos de que el ID de visitante anonimizado sea completamente aleatorio.

¿Puedo excluirme del rastreo de estadísticas?

No, no es posible excluirse. El rastreo de estadísticas está completamente anonimizado y se realiza del lado del servidor.

¿Hay estadísticas de uso para comunidades?

Aún no, pero agregaremos estadísticas de uso agregadas para tus comunidades.

¿Rastrean mis consultas de búsqueda?

No.

¿Realizan algún perfilado manual o automático de usuarios?

No.
